# Agro Assets

Repositório público de assets (logos e imagens) utilizados na plataforma Agro Search.

## Estrutura

logos/ → logos dos portais (PNG, 60x60, fundo transparente)

## Observações

- Repositório público para permitir acesso direto via URL
- Assets são usados apenas para exibição visual
- Código da plataforma fica em repositório separado
